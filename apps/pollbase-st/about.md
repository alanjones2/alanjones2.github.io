# About Pollbase Interactive

Pollbase Interactive is an interactive dashboard for exploring UK voting intentions over time.

The data is derived from Dr Mark Pack's [Pollbase](https://www.markpack.org.uk/opinion-polls/) and contains polling results by date, polling company, publisher, and party vote share.

You can filter the data by date, Party, and Polling Company and download the resulting charts and data.

## How to use it

Use the sidebar controls to narrow down what you see:

- **Time Period** allows you to quickly set the time range of the data to be viewed.
- **Date range** limits the polls shown to the selected period with more flexibility.
- **Parties** this filter selects which party columns are included. The default is all parties.
- **Polling companies** filters the polls by pollster. BY default the following companies are included: YouGov, Ipsos, More in Common, Survation, Opinium, Find Out Now, Deltapoll, BMG Research, JL Partners, Focaldata. Others must be selected specically.

The results are shown across four tabs:

- **Snapshot** gives the standings of the parties for a specific date. The date is the latest in the filtered data, i.e. if you selcet one of the Time period' selections it will be the latest date. If you select a range of date it will be the latest of those dates.
- **Trend** shows each party's vote share over time as a scatter plot, with  LOWESS trendline for each party.
- **Raw Data** shows the underlying filtered polls as a table.
- **About** shows this description.

Changes to the sidebar controls update every tab immediately.

## Download charts or data

Mouse over the chart and, top right, you should see a camera icon (among others) loke the image above; click on that to download the current version of the chart.




To download the data as a CSV file, mouse over the raw data view and click on the download icon on the top right of the data table.
